# OTMS Packer

This directory contains the Packer configuration used to create application AMIs for the OTMS VM deployment model.

Packer creates application AMIs that can be used by Terraform to launch application EC2 instances.

## Applications

| Application | Runtime | Port |
|---|---|---:|
| Frontend | Node.js | 3000 |
| Employee API | Go | 8080 |
| Attendance API | Python | 8081 |
| Salary API | Java | 8082 |
| Notification API | Python | 8085 |

## Prerequisites

The following tools are required:

* Packer
* AWS CLI
* AWS credentials with permissions to create EC2 instances and AMIs
* Application artifact generated by the CI pipeline

## Packer Initialization

Initialize the Packer plugins from the applications directory:

```bash
cd Packer/applications

packer init .
```

## Packer Formatting

Format the Packer configuration:

```bash
packer fmt .
```

## Packer Validation

Validate the Packer configuration before creating an AMI:

```bash
packer validate \
  -var="application=employee" \
  -var="version=1.0.0" \
  -var="artifact_path=/tmp/employee-api" \
  -var="source_ami=ami-xxxxxxxx" \
  application.pkr.hcl
```

The validation step checks that the Packer configuration and supplied variables are syntactically and structurally valid.

## Building an AMI

Build an application AMI using the Packer configuration:

```bash
packer build \
  -var="application=employee" \
  -var="version=1.0.0" \
  -var="artifact_path=/tmp/employee-api" \
  -var="source_ami=ami-xxxxxxxx" \
  application.pkr.hcl
```

Packer launches a temporary EC2 instance from the specified source AMI, copies the application artifact, installs and configures the application, and creates an application AMI.

## AMI Naming

AMI names follow the format:

```text
otms-<application>-<version>
```

Examples:

```text
otms-employee-1.0.0
otms-attendance-1.0.0
otms-salary-1.0.0
otms-notification-1.0.0
otms-frontend-1.0.0
```

## AMI Tags

The generated AMI contains the following tags:

| Tag         | Description           |
| ----------- | --------------------- |
| Name        | Application AMI name  |
| Application | OTMS application name |
| Version     | Application version   |
| Project     | OTMS                  |

## Role in OTMS

Packer is responsible for creating application AMIs.

Terraform is responsible for provisioning the AWS infrastructure and launching EC2 instances from the required AMIs.

Ansible is responsible for configuring the database servers and other required server-side configuration.

Jenkins will later automate the Packer workflow as part of the OTMS CI/CD pipeline.

## Packer Command Summary

| ----------------- | ----------------------------------- |

| `packer fmt`      | Formats Packer configuration files  |
| `packer validate` | Validates the Packer configuration  |
| `packer build`    | Builds the application AMI          |
